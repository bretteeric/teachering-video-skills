# 教科書編排規格

本規格從《AI Agent 架構師訓練手冊-30HRS》萃取而來，`scripts/build_book.py` 已全部實作。
這份文件說明「為什麼這樣排」，供規劃新書與判斷原稿是否合格時參考。

---

## 1. 全書頁序

| # | 區塊 | 頁數 | 頁尾頁碼 | 內容來源 |
|---:|---|---|---|---|
| 1 | 封面 | 1 | 無 | 設定檔：書名、徽章、副標、標語、四篇名稱、代表圖示 |
| 2 | 書名頁 | 1 | 無 | 代表圖示縮小版＋書名＋`title_page_rows` 資料表 |
| 3 | 如何使用本書 | 1 | 無 | `howto`：編排說明、每章固定結構、篇章對照表、提示框圖例 |
| 4 | 目錄 | 數頁 | 無 | 自動產生：前言＋小節、篇、章、H2 節，附頁碼與點線，整行可點 |
| 5 | 前言扉頁＋前言內容 | — | **從 1 起算** | 章號等於 `preface.chapter_num` 的原稿（通常是 `00_課程總覽.md`） |
| 6 | 篇扉頁 | 每篇 1 | 有 | `parts[].name/title/span/desc`＋本篇各章清單 |
| 7 | 章扉頁 | 每章 1 | 有 | CHAPTER NN、所屬篇、章名、副標、主視覺海報、章資訊表 |
| 8 | 章內容 | — | 有 | 原稿本文，H2 起自動換頁 |
| 9 | 索引 | 1～3 | 有 | 自動產生：英文 A–Z 分組＋中文詞彙（依 Big5 碼序，約等於筆畫序），雙欄 |

- **本文頁碼從前言開始算 1**，封面到目錄不編頁碼。目錄與索引的頁碼一律對應頁尾數字。
- PDF 書籤三層：`篇／前言／索引 → 章 → 節`。

## 2. 章節架構（標題層級）

| 層級 | Markdown | 由誰產生 | 範例 |
|---|---|---|---|
| 書名 | `#` | 工具 | `# AI Agent 架構師訓練手冊（30HRS）` |
| 前置頁小標 | `##` | 工具 | `## 如何使用本書`、`## 目錄` |
| 前言 | `#` | 工具 | `# 前言　課程總覽與學習地圖` |
| 篇 | `#` | 工具 | `# 第一篇　架構思維與 AI 協作` |
| 章 | `#` | 工具 | `# 第 3 章　工作區憲法 CLAUDE.md` |
| 節 | `##` | **原稿** | `## 四、概念講解：為什麼 AI Agent 需要工作區憲法` |
| 小節 | `###`～ | **原稿** | `### 4.1 …` |
| 索引 | `#` | 工具 | `# 索引` |

- 「篇」「章」與名稱之間用**全形空白**（`第一篇　架構思維…`、`第 3 章　工作區…`）。
- **原稿不得在程式碼區塊外使用 H1**，章名一律由 front matter `title` 產生（工具會擋下並報錯）。
- 原稿的節、小節編號、圖號（`圖 3-6`）保持原樣；**章號＝Session 編號**，圖號才能與章號一致。

## 3. 原稿規範（輸入端）

每份原稿一個檔案，檔名以兩位數字開頭（`03_工作區憲法CLAUDE.md`），開頭有 front matter：

```yaml
---
session: 03              # 章號（也接受 chapter:）；沒有就用檔名前綴數字
title: 工作區憲法 CLAUDE.md
subtitle: 技術棧、目錄、規範、禁止事項與驗收指令   # 用「、」分隔，會出現在篇扉頁、章扉頁、目錄
duration: 120 分鐘（2 小時）                      # opener_meta 指定的欄位才會顯示
example: 範例/03_claude-md
---

[TOC]                    # 可有可無，編書時會移除

## 一、課程資訊與學習目標
```

- 可用語法：表格、fenced code（``` 與 ~~~，允許四個反引號包三個反引號的巢狀）、` ```mermaid `、
  `!!! tip "標題"` 提示框（tip／warning／info／danger／note）、`- [ ]` 核取清單、
  `{: style="max-height:150mm"}` 屬性。
- 圖片用相對於原稿資料夾的路徑（`images/03/xxx.png`）。成品 `.md` 放在同一資料夾，路徑才不會壞。
- 章與章之間**不要互相用 `](#錨點)` 連結**：合併後錨點會重新編號。

## 4. 各頁版面

整體色系沿用講義：深藍 `#0f2a4a`／`#0b1f3a`、藍 `#1d5fa8`、青 `#0ea5b7`／`#7fe3ee`、橘 `#e67e22`／`#f5a623`。
字型：內文 Noto Sans TC（備援微軟正黑體），書名、篇名、章名用 Noto Serif TC。

**封面**（滿版 A4、無邊界）：深藍漸層＋藍圖格線＋內框線。由上而下：英文書系標語｜橘框徽章（如 `30HRS`）→
代表圖示 → 書名（襯線、兩行、青色光暈）→ 時數／章數統計 → 副標（青）→ 標語（灰藍）→ 各篇名稱卡片列 →
底部：課程指定教材字樣｜版次。

**代表圖示**（SVG，封面與書名頁共用）：中央六角形核心（`core_top`／`core_bottom` 兩行字），
外圈 6 個衛星節點以輻條相連，`accent_nodes` 用橘色、其餘青色；外有虛線軌道與光暈。
節點名稱挑全書最核心的 6 個概念，每個 ≤ 6 個大寫字母。

**書名頁**：白底，深藍圓形底的代表圖示、書名（襯線）、橘框徽章、副標、書籍資料表。

**目錄**：篇（粗體深藍＋上方青線）、章（粗體藍）、節（縮排小字）；每列點線導引到右側頁碼，整列可點。

**篇扉頁**：深藍漸層圓角滿頁、格線；`PART N` → 橘色「第 N 篇」→ 大標篇名 → 範圍（S01～S05）→
篇導讀一段 → 本篇各章（章號｜章名＋副標）。

**章扉頁**：頂端 `CHAPTER NN`（青）｜右側「第一篇・篇名」→ 橘色「第 N 章」→ 襯線章名 → 副標 →
主視覺海報（約 172mm 高，圓角陰影）→ 章資訊表（課程時數｜範例專案）。沒有海報時留虛線框。

**章內容**：沿用講義樣式（`assets/lesson.css`）：H2 深藍底白字色條並自動換頁、H3 藍字底線、
表格斑馬紋、程式碼 highlight.js、mermaid 圖限高一頁、提示框四色。

**索引**：雙欄、欄間細線；分組標頭為深藍色條（A、B、C…、中文詞彙），
每列「詞彙（粗體）……頁碼, 頁碼」，頁碼可點。

## 5. 主視覺（海報）

- 來源：`poster_dir` 中以章號開頭的圖檔（`03 為 AI 立下工作憲法.png`），`00` 給前言。
- 編書時自動縮成長邊 1350px 的 JPEG 放到 `<輸出>/images/book/chNN.jpg`（原圖 2MB × 16 張會讓 PDF 暴增）。
- 缺海報的章仍可編，只是章扉頁為虛線框；可先用 `image-geneate-skill` 補圖再重編。

## 6. 索引

- 條目 60～100 個為宜。來源優先序：
  1. 每章 front matter `subtitle` 的關鍵詞（章的核心概念）
  2. 跨 3 章以上的英文技術名詞（框架、模式、縮寫）
  3. 課程總覽中的名詞對照表
- 排除：動詞與泛稱（撰寫、設計、實作）、檔名、指令、程式識別字、只出現一次的詞。
- 每筆是 `[顯示名稱, 正規式]`：英文用 `\b` 字界避免誤中（`\bService\b`）；同義詞以 `|` 合併
  （`人在迴路|Human-in-the-loop|HITL`）；顯示名稱可加中文說明（`Proposal（提案）`）。
- 頁碼挑選規則（工具自動）：
  1. 詞彙出現在某章章名／副標 → 該章扉頁頁碼優先列入（最多 3 章）
  2. 其餘依「節標題命中 ×5 ＋ 內文次數」排序，只取 ≥ 3 次的節（都不到就全取），合計最多 6 個頁碼
  3. 頁碼依書中順序排列、去重
- 全書找不到的詞會在建置時列出警告並略過——看到警告就修正正規式或刪除該詞。

## 7. Markdown 版與 PDF 版的差異

| 項目 | Markdown | PDF |
|---|---|---|
| 封面 | `images/book/cover.png`（由封面 HTML 截圖，2 倍解析度） | 向量滿版封面 |
| 篇／章扉頁 | H1 標題＋海報圖＋引言區塊（副標、章資訊）＋篇內章節表 | 獨立設計頁 |
| 目錄 | 巢狀清單，連結為 GitHub／VS Code 錨點（中文保留、標點移除、重複加 `-1`） | 點線＋頁碼＋整列連結 |
| 索引 | `[章–節](#錨點)`，例 `[3–5](#…)`、`[第 6 章](#…)` | 頁碼連結 |
| 檔頭 | HTML 註解：本檔自動產生，勿直接修改 | PDF 中繼資料（標題、主旨、關鍵字、作者） |
